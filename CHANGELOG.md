# Revision history for onelastleaf-plugin-sdk

## 0.1.0 -- 2026-08-22

- First public release of the official onelastleaf process-plugin SDK for
  Haskell.
- Provide the plugin runtime, concurrent action dispatch, cancellation, host
  calls, structured logging, and chunked artifact uploads.
- Support Linux, macOS, and Windows with GHC 9.2.8 and 9.6.7.
